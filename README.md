### 🧠 NLP Sentiment Analysis & Emotion-Aware Summarization Pipeline

Dual-path Hindi/English NLP system combining sentiment analysis with context-aware text summarization.

**Status:** Active Research | **Papers:** CISCom 2025

**Architecture:**
- **Sentiment Path:** IndicBERT v2 (Hindi) + Translation Pipeline (Hindi→English)
- **Output:** Structured JSON with emotion labels, polarity scores, intensity, and segment-level analysis
- **Summarization:** Emotion-conditioned abstractive summarization
- **Tech:** PyTorch, Hugging Face Transformers, IndicTrans2

**Challenges Addressed:**
- Multi-lingual sentiment consistency
- Emotion vs. polarity distinction
- Lack of paired training data (synthetic bootstrapping explored)
